🏦 Banking Management System

📌 Project Overview

The Banking Management System is a web-based application developed to manage banking activities easily and efficiently. It helps administrators manage customers, bank accounts, branches, and transactions in one place.

🎯 Objectives

- To simplify banking operations.
- To manage customer and account details.
- To maintain transaction records.
- To provide an easy-to-use dashboard.

✨ Features

- Dashboard: Displays total deposits, customers, accounts, and branches.
- Customer Management: Add and manage customer details.
- Account Management: Manage customer bank accounts.
- Branch Management: View and manage branch information.
- Transaction Management: Manage deposit and withdrawal transactions.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Firebase
